HTML:
HTML stands for Hypertext Markup Language, and it is the standard code used to structure and display content on a web page.

CSS:
CSS stands for Cascading Style Sheets. It is a fundamental style sheet language used to describe the presentation, visual layout, and design of a document written in a markup language like HTML.

JAVASCRIPT:
JavaScript (JS) is a high-level, lightweight, and dynamically-typed programming language used primarily to create interactive and dynamic content on websites.

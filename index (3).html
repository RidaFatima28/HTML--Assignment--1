Computer Storage

Computers use the binary number system to represent and process data. Binary uses only two digits:
      0 and 1.
For example: 1012 is a binary number.

Computer storage is measured in units such as bytes, kilobytes, megabytes,gigabytes, and terabytes.
In binary calculations: 210 equals to 1024.

In early explanations of computer storage, a kilobyte was often described as 1,000 bytes 1,024 bytes in the binary-based convention.

In early era Computers can only store numbers , now Modern computers can store numbers, text, images, audio, video, and other types of digital information.
